# Katkı Rehberi

1. Node 22 ve Python 3.11+ kullanın.
2. Gerçek müşteri verisi veya secret commit etmeyin.
3. Değişiklikten önce `npm run verify:scope`, ardından frontend ve backend testlerini çalıştırın.
4. Public API sözleşmesi değişirse OpenAPI snapshot ve frontend adapter testlerini birlikte güncelleyin.
5. Commit biçimi: `feat:`, `fix:`, `test:`, `docs:`, `chore:`.
